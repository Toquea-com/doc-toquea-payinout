# Bienvenido a la documentación de Payout

Toquea ofrece una solución robusta para la dispersión de dinero, pensada para integrarse de forma sencilla con otras plataformas. Esta documentación está dirigida a desarrolladores e implementadores que deseen incorporar el sistema de **Payouts** de Toquea en sus aplicaciones.

Nuestra API ha sido diseñada para ser simple, eficiente y compatible con distintos entornos, facilitando una integración rápida y segura.

## ¿Por donde deseas comenzar?

[Referencia del api](/operations/createPayout): Consulta los endpoints disponibles, parámetros necesarios y respuestas del sistema.

[Descripción de flujos y lógica](/payout/flow): Revisa cómo funciona el proceso completo de dispersión, desde la solicitud hasta la entrega del dinero.
