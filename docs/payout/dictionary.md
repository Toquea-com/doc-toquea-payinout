
# Diccionario de datos

## Tipo de cuentas

| Nombre clave | Descripción |
|:---:|:---:|
|CurrentAccount| Cuenta corriente |
|SavingsAccount| Cuenta de ahorros |
|CellphoneNumber| Billeteras digitales  |

En el caso ***CellphoneNumber** el pago no se limita únicamente a billeteras digitales (como Yape, Plin o Bim), sino que también puede realizarse a entidades financieras (ver lista de bancos) asociadas al número de celular. Por ejemplo, un mismo número de celular podría estar vinculado a tres entidades distintas: Yape, Plin y Banco Pichincha.
